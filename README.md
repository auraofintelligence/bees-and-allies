A question-led, multi-page public website for everyday beekeepers, bee people and allies exploring a locally led Straddie bee resilience lab.

**Public site:** <https://auraofintelligence.github.io/bees-and-allies/>

The site is built as static HTML, CSS and JavaScript for GitHub Pages. It keeps the public framing careful:

- local beekeepers are treated as people already acting, not passive observers
- universities and agencies are invited as supporting partners
- biosecurity and treatment language links to official sources
- the lab and future institute pathway are framed as questions and staged possibilities
- each page uses a custom generated full-frame hero image

## Pages

- `index.html` - public gateway
- `local-hives.html` - local hive observations and census
- `island-lab.html` - digital-twin-first new capacity model
- `biosecurity.html` - careful reporting, movement and permit edges
- `research.html` - surveillance, response and native plant testing gates
- `partners.html` - partner pack and co-op stewardship table
- `institute.html` - staged institute and field school pathway
- `sources.html` - source links and image notes

## Status and boundaries

This is a question-led concept, not an operating laboratory, biosecurity authority, research partnership or claim of local endorsement. Hive movement, pests, diseases and treatments should be checked against the current official sources linked from the site. Generated hero images are illustrations, not documentary evidence.

## Local preview

Open `index.html` in a browser, or run a small local server:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.
